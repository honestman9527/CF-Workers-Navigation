# CF Workers Navigation

CF Workers Navigation 是一个部署在 Cloudflare Workers 与 D1 上的个人书签导航应用。你可以把常用网站集中保存，用多级分类和标签整理，在统一首页浏览、搜索和访问，也可以将公开书签分享给访客，把私有内容留给自己。

项目面向个人维护，提供访客浏览与管理员登录两种访问方式。Web 前端与 Worker API 作为同一个部署单元运行，书签数据存储在 D1 中。

## 主要功能

- **分类导航**：首页集中展示常用网站和分类分区，支持逐层浏览多级分类、查看分类路径和按需加载更多书签。
- **两种搜索模式**：站内搜索用于查找已保存的书签，可结合标签筛选；网页搜索支持切换搜索引擎、bang 搜索和网址直达。
- **书签管理**：登录后可在首页添加、编辑书签和设置常用；管理后台提供书签筛选、归档、回收站，以及分类和标签整理。添加书签时可自动补全标题、描述与图标。
- **公开与私有内容**：分类和书签均可设置访问权限，私有分类的保护会沿层级继承；访客只能查看公开且处于活动状态的内容。
- **导入与导出**：支持 JSON 备份和浏览器书签 HTML，方便迁移已有收藏。JSON 可保留分类、标签、权限、常用及归档、回收站状态，适合完整备份。
- **外观与偏好**：支持亮色、暗色、跟随系统、背景图片与搜索引擎配置，前台和管理后台均适配桌面与移动端。

## 技术组成

| 部分     | 技术与职责                                                         |
| -------- | ------------------------------------------------------------------ |
| 运行平台 | Cloudflare Workers 承载 API，Workers 静态资源托管 Web，D1 存储数据 |
| 服务端   | Hono 处理 HTTP 路由，Drizzle ORM 管理数据访问，Zod 验证输入        |
| 前端     | React、TanStack Router、Tailwind CSS 和 Vite                       |
| 组件     | 前台使用定制组件，后台使用 shadcn/ui，交互可复用 Base UI           |
| 跨端契约 | TypeScript 共享 API 类型、端点与客户端，统一放在 `src/shared`      |
