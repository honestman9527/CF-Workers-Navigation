# 文档维护

本文件约束项目文档维护；根目录 [AGENTS.md](../AGENTS.md) 统一规定任务流程、Git 授权与验证标准。

## 职责边界

- `README.md` 提供项目简介与文档入口；[index.md](index.md) 面向读者索引主题，不承载行为细节。根任务路由面向代理，按触发场景定位文档。
- [architecture.md](architecture.md) 维护服务与运行时边界、权限继承、分页及缓存机制和取舍；[api.md](api.md) 维护 HTTP 路由、跨端契约、认证协议、访问范围、参数和错误码。
- [database.md](database.md) 维护数据模型、索引、触发器、查询预算与迁移兼容规则；[deployment.md](deployment.md) 维护部署目标、密钥、发布验证、远程迁移执行与恢复步骤。
- [usage.md](usage.md) 维护用户可观察的页面交互、失败恢复、本地开发与视觉确认清单；[DESIGN.md](../DESIGN.md) 维护视觉规范、主题、对比度、焦点可见性与动效呈现。
- [import-export.md](import-export.md) 维护文件格式、兼容性、匹配策略、限制、部分写入和取消语义；其他文档引用这些传输规则。

## 维护步骤

1. 按根任务路由读取相关主题，以源码、配置、迁移和自动化流程核对当前事实。
2. 将每条规则与取舍写入其职责文档；其他主题只保留本场景的说明并链接权威位置。协作与授权规则只在根 AGENTS.md 定义，命令与版本以配置为准，文档只保留必要的使用示例及注意事项。
3. 交互变化在 usage.md 更新入口层级、桌面/移动端显隐与展开方向、键盘操作和关闭后的焦点恢复；区分首次加载失败、刷新保留数据与操作保留草稿，传输取消行为链接 import-export.md。动态信息说明时间来源和更新方式；动效变化在 DESIGN.md 说明呈现与减少动态偏好的行为。
4. 新增、移动、删除文档或调整职责时，同步根任务路由、文档索引和受影响链接；替换重复或过时说明，保留兼容边界，不把计划或未验证结论写成当前行为。
5. 按根 AGENTS.md 验证改动；完成标准是规则归属清晰、相关描述一致、改动文件格式与本地链接检查通过。
