# 使用与本地开发

## 产品页面

`/` 直接打开统一的书签柜导航首页。外观配置（主题基底、4 套主题色、视图密度、壁纸遮罩浓度与首屏防闪烁恢复）见[视觉设计规范](../DESIGN.md)；浏览器禁止本地存储时，偏好仍在本次页面会话中生效，重新打开页面后恢复默认值。

公开设置首次加载失败时，搜索区上方显示错误与「重试设置」，保留导航内容及搜索输入，并暂用默认搜索引擎；重试过程中显示加载状态且不重复请求。已有设置刷新失败时继续使用上次成功的值，后台保存成功后同步更新前台。

### 通用交互约定

- 首次加载失败显示具体错误与原地重试入口；刷新失败保留已有数据，操作失败保留编辑草稿。
- 加载或提交期间禁用重复操作，提供可感知的进度文案；操作成功后移除相应错误。
- 同一书签正在写入时，冲突操作提示「该书签正在处理中，请稍后重试」；保存冲突在编辑器内显示并保留草稿，待原操作完成后可重试。
- 弹出菜单、抽屉与命令面板关闭后恢复触发点焦点；分类筛选与移动浮层的关闭行为见[管理后台](#管理后台)。

### 分类浏览与轻管理

- **导航布局**：桌面左侧显示品牌、`Cmd/Ctrl + K` 命令面板入口、可折叠两级分类树（含受保护的内置「常用」、普通一级与二级分类及计数、未分类）与底部单行外观/管理栏，支持顶部按钮、`Cmd/Ctrl + B` 或命令面板折叠为 `72px` 紧凑图标栏（悬停/聚焦显示浮层提示，收起后网格按容器宽度自动扩列）；`< lg` 移动端与平板使用吸顶顶栏与左侧滑出抽屉，选择分类后自动收起并恢复焦点。
- **分类与分组**：分类最多两层，首页 `/` 默认展示内置「常用」一级分类（支持改名、改图标、改权限、拖拽与一键排序及新建二级子分类；不可删除或降级为子分类；访客无任何可见分类时自动降级展示未分类）。点击一级或二级分类展示所属一级下所有二级分组，一级直属书签单列在“直属书签”组（有二级且无直属时隐藏），空二级保留标题与空状态。各分类直属与未分类书签按分类内顺序排列，新建或移入书签默认追加到分类末尾。主工作区顶部与外观面板均支持「舒适卡片 / 紧凑网格」切换。卡片展示图标、名称、一行描述（缺少时显示域名）、所属分类、最多 3 个可点击标签（超出以 `+N` 提示）及私有锁徽章。
- **分页与缓存**：未分类和搜索结果使用单个列表；分类浏览各组（含内置「常用」）独立首批加载 12 项，点击「展开更多」追加 24 项，错误与重试仅作用于该组。内存范围缓存与取消语义见[架构与服务边界](architecture.md#分页与查询行为)。
- **登录轻管理与拖拽排序**：登录后页头提供添加书签，卡片提供拖拽排序手柄、「复制到分类」、编辑与移入回收站（桌面支持悬停的指针设备使用右上角悬浮胶囊，浮层打开期间保持悬浮栏可见，触控端常显操作条并保证 44px 热区）；点击「复制到分类」可在顶部一键「复制到常用」或在两级分类树与未分类中选择目标，受继承私有保护的书签复制时会自动保持私有；移入回收站需二次确认，归档、恢复、永久删除以及分类和标签整理进入后台。在分类直属分组（含内置「常用」及其子分类）或未分类中，桌面端可直接拖动手柄调整顺序，也可点击分组头部「排序」进入排序模式使用前移/后移按钮、键盘（`Space`/`Enter` 拾取、方向键移动、`Esc` 取消）及「按名称 / 按添加顺序 / 按最新添加」一键排序。会话失效或登出立即卸载原身份状态与草稿；网络临时错误保留已确认身份与草稿并在恢复后继续检查。
- **命令面板**：`Cmd/Ctrl + K` 或点击命令按钮唤起，支持键盘上下选择、回车执行、`Esc` 关闭与中文输入法防误触发，整合站内快速检索、分类切换、主题/配色/视图密度/侧栏折叠切换及管理入口。

### 搜索与链接兼容

- **模式与筛选**：搜索分为「站内」和「网页」，首次默认站内，随后记住浏览器最后模式，链接显式 `mode=site|web` 优先；切换模式保留输入。站内支持分类、关键词与标签/无标签组合，切换一级保留关键词和标签；清除条件后，常用入口回到常用，其他分类保留分类并恢复缓存与原滚动位置。站内模式输入网址不触发跳转。
- **网页模式与快捷键**：网页模式支持引擎选择、bang 搜索与网址直达；只有 bang 前缀而无关键词时禁用提交，链接指定不可用引擎时保留选择并要求重选。`/` 聚焦搜索，上下键选择站内结果、回车打开，`Esc` 清除搜索；中文输入法组合期间不触发快捷操作或提交。
- **URL 与旧入口兼容**：URL 使用 `mode`、`q`、`engine`、`category`、`tag`、`untagged`（`tag` 优先于 `untagged`）。`category` 保存当前一级或二级 slug；旧二级深链接展示所属一级的全部分组并在无历史滚动位置时定位对应二级标题（带搜索条件则限定该二级）。分类不存在或无权访问时清除分类并提示返回默认入口。`/launch`、`/workspace` 分别重定向网页、站内模式，保留有效参数并丢弃旧分页与布局参数。

### 管理后台

- **布局与导航**：`/admin` 提供概览、书签、分类、标签、设置和导入导出。桌面侧栏支持展开态与 `72px` 图标栏（`Cmd/Ctrl + B`），底部工具栏与前台镜像统一；`< lg` 使用抽屉，切换主题保留抽屉，返回前台关闭抽屉，收起侧栏后仍监听系统主题。退出期间禁止重复操作，失败后可重试；操作提示跨管理页面保留。
- **书签、分类与标签整理**：书签页支持状态、分类（含子分类一级分类下可勾选「仅直属」）、标签与关键词筛选及 10/20/50/100 分页；活动行提供「复制到分类」快捷浮层；在使用中状态且按单一分类直属或未分类查看（无搜索/标签筛选）时，支持表格行拖拽手柄与上移/下移调整顺序。分类管理树默认收起，内置「常用」显示「内置」徽标且不显示移动/删除入口；新建子分类展开父分类，刷新保留展开状态；移动使用独立树形浮层，提示权限继承变化并支持外部点击、`Esc` 关闭与焦点恢复；删除普通分类时与未分类网址冲突的书签将自动进入回收站并保留私有保护。标签支持合并（失败保留目标选择，无其他目标时禁用）。
- **可搜索单选与键盘操作**：前后台分类选择及标签筛选使用可搜索单选浮层，空间不足自动避让。分类树默认仅展开选中项父级，搜索展示匹配项及父级，支持方向键展开/收起/移动、`Home`/`End`、`Enter`/空格选择、`Esc` 关闭并恢复焦点。人工确认需覆盖两层折叠、长路径、父级名称搜索、空结果、私有标记及弹窗内浮层关闭顺序。
- **数据加载与编辑**：首次加载失败显示重试入口；刷新失败保留原数据与草稿。书签编辑的保存禁用、自动填写、自定义图标折叠、标签输入及中文输入法防误触规则前后台一致；导入导出规则见[导入与导出](import-export.md)。访客与管理员权限边界见[架构与服务边界](architecture.md)及[API 与权限](api.md)。

### 视觉确认

验证标准见根 [AGENTS.md](../AGENTS.md#风险匹配验证)，视觉基线见 [DESIGN.md](../DESIGN.md#本项目组件与状态规则)。人工检查覆盖：

- 桌面（1440px）、平板（768px）与手机（375px）无横向溢出与错位；
- 前后台侧边栏展开 / `72px` 图标栏切换、Tooltip 定位、`Cmd/Ctrl + B`、刷新防闪烁与容器查询扩列；
- 明暗模式（`vt-theme-ripple` 光圈过渡）、4 套主题色、视图密度切换、自定义背景图与遮罩浓度（25%–95%）；
- 现代动效与交互：书签卡片交错入场、悬停微抬与指针微光、图标轻倾、复制浮层弹性展开及触发栏保持、后台设置 Tabs 滑动胶囊、顶部滚动进度丝带与 `<details>` 平滑展开；
- 桌面书签拖拽排序与键盘排序：分类卡片网格与后台书签表格拖拽手柄、悬停/拖拽抬起与放置指示线（含 `Esc` 取消与 FLIP 落位动画）、排序模式一键重排过渡与 `forced-colors: active` 指示线高亮；
- `prefers-reduced-motion: reduce` 下抑制位移/缩放/View Transitions/进度丝带，高对比度 / Forced Colors 焦点环与色卡保留；
- 触控端 44px 常显热区、移动抽屉、`Cmd/Ctrl + K` 命令面板，以及长文本、加载、错误和反馈状态。

## 本地启动

要求 Node.js `>=24`、pnpm `>=12`。

```bash
pnpm install
cp .dev.vars.example .dev.vars   # Windows PowerShell: Copy-Item .dev.vars.example .dev.vars
```

编辑 `.dev.vars`，为 `ADMIN_PASSWORD` 和 `SESSION_SECRET` 设置仅供本地使用的值。然后初始化本地 D1 并启动：

```bash
pnpm db:migrate:local
pnpm dev
```

打开 `http://localhost:8787`。`pnpm dev` 会先构建 Web，再并行启动 `dev:worker` 和 `dev:web`（监听模式保留既有静态产物，避免 Wrangler 并行启动时出现短暂 404）；如已有进程遇到 404，停止后重跑 `pnpm dev` 即可。

## 常用命令

```bash
pnpm dev                 # 启动本地 Worker 与 Web 构建监听
pnpm dev:web             # 单独监听并重新构建 Web
pnpm dev:worker          # 单独启动 Worker，需要已有 Web 构建产物
pnpm build               # 构建 Web 到 dist/web
pnpm cf:typegen          # 按 Wrangler 配置生成 Worker 绑定声明
pnpm cf:types:check      # 检查 Worker 绑定声明与 Wrangler 配置一致
pnpm lint                # 静态检查
pnpm fmt:check           # 格式检查
pnpm typecheck           # 检查 shared、Worker、Web 与 Worker 测试，最多两项并行
pnpm test                # 运行单元测试和 Worker 集成测试
pnpm check               # 依次运行格式、lint、类型和测试检查
pnpm db:migrate:local    # 应用本地 D1 迁移
pnpm db:migrate:remote   # 应用远程 D1 迁移
pnpm run deploy          # 构建 Web 并部署 Worker
```

`pnpm check` 按格式、lint、类型检查、测试四阶段顺序执行（最多两路并行类型检查，任一失败提前中止）。`pnpm cf:typegen` 将 Wrangler 绑定生成到 `src/worker/bindings.d.ts`，修改绑定后运行 `pnpm cf:types:check` 校验。数据库与部署维护分别见[数据库与迁移](database.md)和[部署](deployment.md)。

## 目录结构

```text
src/
├── worker/       # Hono 路由、D1 服务、Drizzle schema 与备份格式
├── web/          # React Web 前端
└── shared/       # Web 与 Worker 共用的 API 和偏好契约
public/           # Web 静态资源
migrations/       # D1 基线和递增迁移
test/
├── unit/         # shared 与 Web 单元测试
└── worker/       # Cloudflare Worker 集成测试
```

这是单包仓库，Worker 与 Web 共享同一部署配置。
