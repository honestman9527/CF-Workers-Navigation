# Web 视觉：公开导航与私有书签柜

产品：管理员维护的公开导航与私有书签柜。游客免登录浏览公开内容，管理员登录后查看和整理全部内容。

## Token

| 角色         | 浅色      | 深色      |
| ------------ | --------- | --------- |
| 纸面 paper   | `#f5f5f7` | `#1d1d1f` |
| 墨 ink       | `#1d1d1f` | `#f5f5f7` |
| 淡墨 muted   | `#6e6e73` | `#a1a1a6` |
| 线 rule      | `#d2d2d7` | `#424245` |
| Action Blue  | `#0066cc` | `#2997ff` |
| 侧栏 sidebar | `#ffffff` | `#252527` |

字体：正文与标题使用 `Geist`，网址与计数使用 `Geist Mono`。

## 布局

```
┌ login ─────────────────────┐     ┌ 启动台 /launch ─────────────────────────┐
│           印               │     │  header: 标识 + 菜单（含「书签柜」）     │
│          书签柜             │     │                                         │
│        [密码] [进入]        │     │        [ 搜索书签或网站 ◉引擎 ]          │
└────────────────────────────┘     │     [fav][fav][fav][fav][fav]            │
                                   │      常用网站（置顶书签）瓦片             │
                                   └─────────────────────────────────────────┘
                                   ┌ workspace /workspace ───────────────────┐
                                   │ 侧栏品牌       │ 切换索引 + 添加 + 菜单  │
                                   │  ╭─ 浮动索引 ─╮  搜索                  │
                                   │  │ 分类        │  标题 + 视图切换         │
                                   │  │ 标签        │  书签卡片                │
                                   │  │ 全部网站    │                          │
                                   └───────────────────────────────────────┘
```

签名：淡灰纸面上的浮动圆角索引栏，让书签卡片像触手可及的应用条目。用唯一的 Action Blue 标识当前选择与主动作，其余层级由留白、细线和低对比表面建立。卡片是实体点击面，不是玻璃拟态。

背景图片：管理后台「设置」可配置一张全站背景图（启用开关 + https 网址 + 预览），启动台与工作区共用同一张；以主题化的实体半透明 overlay 保证可读性，登录页与管理后台保持纯色。背景默认关闭。全站不使用装饰性渐变。

内容卡片与输入最多使用 8px 圆角；搜索框、标签和主操作可使用胶囊形。卡片通过白/近黑实体表面和细线区隔，默认无阴影，覆盖层只允许低阴影。错误和危险状态使用语义红色，不作为品牌强调色。

### 启动台（命名路由 `/launch`）

根路径 `/` 按记忆的前台偏好重定向（无需登录）（启动台或书签柜）。启动台：居中搜索胶囊 + 关键词为空时展示常用网站瓦片。

- 搜索胶囊：放大镜 + 输入框 + 引擎切换 chip（Action Blue 的唯一强调）。书签 FTS 全量匹配（不依赖分类/标签，`!g` bang 语法、URL 直达、↑↓/Enter 选择；回车逻辑铺满「打开书签 → 网页搜索」）；搜索结果以「常用网站」同款 favicon 瓦片样式展示在对应主区域位置（非下拉 dialog、非列表），末位附「搜索引擎搜索」瓦片，Web 端一律新标签打开。
- 关键词与手动选择的引擎写入地址栏（`/launch?q=&engine=`，防抖 replace），刷新/回退保留；清空关键词恢复常用网站瓦片。
- 常用网站：置顶书签的 favicon 瓦片网格（`auto-fill minmax(8.5rem,1fr)`），优先级低于搜索（有关键词时不显示），一次性加载全部置顶书签；瓦片是实体卡片，hover 上浮 + Action Blue 描边；空态引导「前往书签柜」置顶。
- 搜索引擎来自服务端设置（管理后台设置页管理），缺省回退内置默认列表。
- 顶栏：与工作区共用同一套 AppHeader（品牌 + 右上角下拉菜单），「书签柜」入口收纳进菜单、不再占用独立按钮；菜单含主题切换、管理后台、退出；按 `/` 聚焦搜索。

### 顶栏菜单

书签柜的整理入口集中在右上角下拉菜单，顶栏只保留「添加书签」主按钮：

- 视图：网格 / 列表单选（本地偏好，不入 URL），移到主区域标题行右侧的分段切换，不再占用菜单。
- 启动台：回到 `/launch` 启动台首页（启动台页面的菜单对应提供「书签柜」项）。
- 归档 / 回收站：不再作为工作区视图，统一收进管理后台「网站」tab 管理（归档、移入回收站操作仍在卡片上）。
- 导入 / 导出已移入管理后台的「数据」tab，顶栏不再提供数据入口。
- 主题切换（亮色、暗色、跟随系统）、管理后台、退出。

启动台与工作区复用 AppHeader、Brand 和菜单组件。启动台保留品牌顶栏；书签柜将 Logo、名称和副标题放入浮动侧栏顶部，右侧工具栏整合索引切换、搜索、添加书签和菜单，工具栏背景透明且不设底部分隔线，让全站背景图连续显示；搜索框保留独立底色以保证可读性。顶部不再占用独立的「导入 / 导出」按钮，数据备份与恢复统一收进后台，窄屏顶栏更精简。

### 侧边栏（响应式）

工作区与后台共用 shadcn Sidebar：1024px 及以上使用可收起桌面浮动栏，更窄时使用 Sheet 抽屉；支持 Escape 关闭、焦点恢复与背景滚动锁定，选择导航项后自动关闭抽屉。

工作区索引顺序固定为「全部网站 → 分类 → 标签」，全部网站下可展开「未分类」「无标签」两个二级入口。全部网站子项、分类和标签分组默认展开，可独立收起并本地记忆；导航到对应分类/标签时展开分组；无数据时显示简短空态。三组放在同一个 SidebarContent 内，内容自然排列，超过视口可用高度时整体纵向滚动；分类树与标签列表不再分别滚动。滚动条保留，阻止滚动穿透，不产生横向滚动。

- 裸 `/workspace` 直接加载全部活动书签，不再读取或写入分类记忆。品牌按钮也进入全部网站。
- 分类、标签、未分类和无标签是互斥导航，点击时清除其他筛选和搜索词；重复选择保持选中。全部网站清空筛选。
- 常用入口不再出现在侧栏，置顶操作、启动台常用网站及后台常用筛选继续保留。旧 `pinned=true` 深链仍可访问常用书签。
- 旧组合链接按「分类 → 标签 → 无标签 → 置顶」优先级收敛为一个导航条件。仅在分类/标签索引成功加载且确认当前项已失效后回到全部网站；加载失败仅报错，不改写当前位置。
- 工作区按服务端 offset + total 页码分页，默认每页 24 条，可选 24/48/96；页码与条数写入 URL，默认值省略。切换导航、搜索或条数时回第一页；切换网格/列表保留页码；末页越界自动收敛。搜索全量匹配活动书签，不叠加导航筛选；清空搜索回到当前导航位置的第一页。

书签柜采用 floating + offcanvas 侧栏：右侧内容工具栏左侧始终显示展开／收起按钮，支持 Ctrl/Cmd+B，桌面默认展开并独立记忆本地偏好。完全收起后不占内容宽度，隐藏内容不可键盘聚焦；减少动态效果偏好下取消过渡。

桌面面板、占位和移出距离共用 `--sidebar-width: clamp(17.5rem, 22vw, 20rem)`，浮动面板贯穿视口高度并避开安全区，保留 12px 外侧留白，品牌区固定在侧栏顶部，内部独立纵向滚动。1024px 以下使用不超过 88vw 的抽屉，选择筛选后关闭，移动状态不覆盖桌面偏好。

全部网站、未分类和无标签位于品牌区下方，其后为可独立折叠的分类与标签。书签柜分类行按「图标、私有锁、直属计数、名称、右侧展开箭头」排列，不显示 LV 和权限文字徽标；每层缩进 12px，累计最多 48px。长名称截断，悬停和键盘聚焦提示完整名称与私有来源，屏幕阅读器可读出权限。后台和分类选择器保留原布局。

### 分类与标签操作

- 分类沿用可折叠树，书签柜每行显示图标、私有锁图标、直属活动书签计数、名称和右侧展开箭头。箭头仅展开/收起，主体进入分类及其子树。
- 标签在侧栏纵向列出名称和活动书签计数，内容区不再保留标签筛选面板。
- 「未分类」表示没有分类，「无标签」表示没有任何标签；二者不同。全部网站右侧箭头独立折叠其子项，点击名称仍进入全部网站；导航到未分类或无标签时自动展开子项。
- 卡片上的分类和标签采用同样的互斥导航规则。
- 活动书签整张卡片支持新标签页打开；置顶、归档、编辑、删除、分类与标签为独立控件。
- 添加/编辑时保留标签输入、已有标签建议与可折叠分类树选择，分类提交仍使用 `categoryId`。

### 管理后台（站内侧边栏页）

分类、标签与设置不再以弹窗形式存在于工作区，统一收到独立的「管理后台」页（从右上角菜单进入），采用侧边栏式导航（桌面端常驻浮动栏、移动端抽屉），主工作区保持书签浏览与卡片操作能力：

- 概览：四态书签计数 + 分类/标签数统计卡片，可一键进入对应管理栏。
- 网站：统一的轻量级网站（书签）数据表格管理——全状态浏览（全部/正常/已归档/回收站）、搜索、分类/标签筛选、「仅常用」；固定宽紧凑表格（`table-fixed`，行内只保留标题与网址并截断，避免横向滚动），页码分页可选 10/20/50/100，分类筛选为可折叠树（带 `LV` 层级徽标）；支持新建/编辑、置顶、归档、移入回收站、恢复与永久删除（危险操作二次确认），摆脱前台书签柜的重型卡片感。
- 分类：带清晰树形导轨（Tree Guide Lines）与层级阶梯的树形管理（分级折叠，节点带 `LV1/LV2…` 层级徽标；新建一级/子级、重命名、改图标、同级上下移、「调整层级/移动到…」改父级、删除）；书签数显示为「直属 / 含子类总数」；删除确认会说明将上移的子分类数与改为未分类的书签数。
- 标签：列表 + 计数 + 筛选；新建、行内重命名、合并到其他标签、删除；合并与删除均有确认与影响说明。
- 设置：访问与隐私、外观、网站图标、搜索引擎四个标签页共享草稿；保存栏保持可见，撤销修改恢复最近加载/保存的全部配置。加载失败可重试，保存成功同步前台共享缓存。背景图片（开关 + 网址 + 预览）+ Favicon 自动获取工具与开关 + 搜索引擎管理（内置预设 + 自定义引擎增删改、默认引擎单选；内置项不可删除，改动保存到服务端，启动台跨设备生效）。
- 数据：导入 / 导出（导出 JSON 完整备份与 HTML 浏览器书签、拖放导入并自动识别格式），原顶栏菜单的数据入口已移除。

后台 tab 与工作区筛选均由 URL 驱动（`/admin/<tab>` 与 `/workspace?category=&tag=&untagged=&pinned=&q=&page=&pageSize=`），可直接深链、可回退；无筛选的裸 `/workspace` 直接展示全部活动书签。后台沿用主工作台的视觉 token 与圆角语言，侧边栏用 shadcn Sidebar 原语（`SidebarProvider` / `Sidebar` / `SidebarInset` + `SidebarTrigger`），桌面常驻浮动圆角栏、移动端抽屉，导航项选中态随当前路径高亮，底部提供动态「返回启动台 / 返回书签柜」（基于前台 UI 记忆状态）与「退出登录」。

### 前台双 UI 状态记忆

系统提供两种前台体验：启动台（`/launch`）与书签柜（`/workspace`）。

- 状态记忆：用户在前台切换访问任一界面时，将自动记录最近访问的偏好视图。
- 书签柜保留网格/列表的本地偏好；不再保存分类位置，已有旧分类记忆键不再使用。
- 登录重定向：登录完成或访问根路径时，自动跳转至记忆的前台视图。
- 后台返回联动：从管理后台侧边栏底部点击返回时，按记忆返回对应的启动台或书签柜，而非写死跳转书签柜。

### 危险操作确认

凡是不可逆或影响面大的操作必须二次确认（`AlertDialog`，取消为默认焦点）：书签「移入回收站 / 归档 / 永久删除」，分类「删除」，标签「删除 / 合并」。确认文案明确说明影响与恢复方式；确认后请求期间按钮禁用，成功后以 toast 反馈。恢复、置顶、编辑等轻操作不弹确认。

## 组件组合

界面不手写临时 markup，一律从项目内本地化的 shadcn/base-nova 组件（`src/web/components/ui`）组合：

- 骨架与导航：Sidebar 系（侧边栏索引、导航结构），配合 AppShell 工作台壳。
- 覆盖层：Dialog、AlertDialog；覆盖层必须带标题，视觉隐藏用 `sr-only`。
- 内容块：优先使用现有 Card 系；简单空状态和加载占位可保持功能内局部结构，不为一次性布局新增组件文件。
- 表单：Field 组合（Field + FieldLabel + Input / Select / Textarea / Checkbox），校验用 `data-invalid` + `aria-invalid`。
- 反馈与点缀：优先使用已安装的 toast、Badge、Separator、DropdownMenu 等，不保留未使用的 UI 文件。
- 图标只用 lucide-react，按钮内图标走 `data-icon`，不写尺寸类。

以上是组合惯例：具体以 `src/web/components/ui` 中已安装的组件为准，缺的组件按需补装进同一目录，而不是手写自定义结构替代。配色只走语义 token（paper/ink/rule 落到 background/foreground/border，Action Blue 落到 primary 等），组件不写死 hex，也不做手写 `dark:` 覆盖。

## 不做什么

不套奶油底+衬线模板的大数字 hero；不套黑底酸绿；Web 统一使用 paper / ink / rule / Action Blue 语义 token。

### 工作区内容布局与品牌

工作区最大宽度 90rem，工具栏、标题、网格和分页共用对齐线；搜索整合进吸顶工具栏，桌面限制最大宽度 42rem，640px 以下独占第二行，保留 `/` 聚焦与 Escape 清空。内容标题采用更紧凑的字号与计数间距。网格根据内容容器宽度排列：560px 以下一列，560/900/1200px 起分别两/三/四列，最多四列。卡片标题最多两行，星标常驻，编辑、归档和移入回收站收入更多菜单；空描述不显示占位文案。底部分页显示总数、范围、条数选择和页码，窄屏简化为上一页/当前页/下一页。

本站 favicon 和品牌图标使用 hm-light.svg / hm-dark.svg，随解析后的应用主题同步，资源 URL 带版本参数；主题支持亮色、暗色和跟随系统。后台面包屑显示当前页面；正常对应 API active，已归档对应 archive。设置内容居中且最大宽度 64rem，四个标签页保留统一保存语义，网站图标来源预设只读、自定义可编辑。

## 游客与权限设置

游客顶栏显示「游客 · 浏览公开网站」和登录入口，保留主题及前台切换；隐藏添加、编辑、常用切换、归档、删除和后台入口。游客空态提示暂无公开网站，不显示私有数量或锁定占位。登录入口保留当前站内地址，登录后恢复；私有分类深链按失效分类规则回到全部网站。

分类新建、权限编辑和网站表单使用公开/私有单选。私有徽标区分「私有」与「受上级分类限制」；私有父级下选择公开不会立即公开，说明移动到公开分类后才按自身设置生效。分类移动浮层和网站移动表单明确提示可能公开；删除分类说明原有私有保护保留。

「访问与隐私」设置分别控制新分类、新网站默认权限，初始公开，仅作用于新建；旧内容保持私有。保存与撤销复用全部设置草稿。JSON v2 保存权限；HTML 导出提示不保存权限，旧 JSON/HTML 新导入内容默认私有。
