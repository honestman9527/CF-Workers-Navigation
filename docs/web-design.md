# Web 视觉：私人书签柜

产品：一个人每天打开的书签柜。不是公开导航、不是 SaaS 后台。

## Token

| 角色         | 浅色      | 深色      |
| ------------ | --------- | --------- |
| 纸面 paper   | `#f5f5f7` | `#1d1d1f` |
| 墨 ink       | `#1d1d1f` | `#f5f5f7` |
| 淡墨 muted   | `#6e6e73` | `#a1a1a6` |
| 线 rule      | `#d2d2d7` | `#3a3a3c` |
| 青釉 seal    | `#1c6b5a` | `#7bd3b7` |
| 侧栏 sidebar | `#f0f0f2` | `#242426` |

字体：正文与标题使用 `Geist`，网址与计数使用 `Geist Mono`。

## 布局

```
┌ login ─────────────────────┐     ┌ 启动台 / ─────────────────────────────┐
│           印               │     │  header: 标识 + 菜单（含「书签柜」）     │
│          书签柜             │     │                                         │
│        [密码] [进入]        │     │        [ 搜索书签或网站 ◉引擎 ]          │
└────────────────────────────┘     │     [fav][fav][fav][fav][fav]            │
                                   │      常用网站（置顶书签）瓦片             │
                                   └─────────────────────────────────────────┘
                                   ┌ workspace /workspace ───────────────────┐
                                   │ header: 标识 + 添加 + 菜单（含「启动台」） │
                                   │  ╭─ 浮动索引 ─╮  搜索                  │
                                   │  │ 全部、常用入口│  标签筛选按钮 + 面板     │
                                   │  │ 、分类        │  标题 + 视图切换         │
                                   │  └──────────    │  按分类分组的书签卡片     │
                                   └───────────────────────────────────────┘
```

签名：淡灰纸面上的浮动圆角索引栏，让书签卡片像触手可及的应用条目。用一处青釉色标识当前选择与主动作，其余层级由留白、圆角、低对比线条建立。卡片是实体点击面，不是玻璃拟态。

背景图片：管理后台「设置」可配置一张全站背景图（启用开关 + https 网址 + 预览），启动台与工作区共用同一张；以主题化的半透明 overlay 保证可读性，登录页与管理后台保持纯色。背景默认关闭。

### 启动台（默认首页 `/`）

打开应用先进启动台：居中搜索胶囊 + 下方常用网站瓦片。工作区保持在 `/workspace`，两种布局可自由切换。

- 搜索胶囊：放大镜 + 输入框 + 引擎切换 chip（青釉强调的唯一一处）。书签 FTS 结果下拉（`!g` bang 语法、URL 直达、↑↓/Enter 选择；回车逻辑铺满「打开书签 → 网页搜索」）；Web 端一律新标签打开。
- 常用网站：置顶书签的 favicon 瓦片网格（`auto-fill minmax(8.5rem,1fr)`），瓦片是实体卡片，hover 上浮 + 青釉描边；空态引导「前往书签柜」置顶。
- 搜索引擎来自服务端设置（管理后台设置页管理），缺省回退内置默认列表。
- 顶栏：与工作区共用同一套 AppHeader（品牌 + 右上角下拉菜单），「书签柜」入口收纳进菜单、不再占用独立按钮；菜单含主题切换、管理后台、退出；按 `/` 聚焦搜索。

### 顶栏菜单

书签柜的整理入口集中在右上角下拉菜单，顶栏只保留「添加书签」主按钮：

- 视图：网格 / 列表单选（本地偏好，不入 URL），移到主区域标题行右侧的分段切换，不再占用菜单。
- 启动台：回到 `/` 启动台首页（启动台页面的菜单对应提供「书签柜」项）。
- 归档 / 回收站：切换工作区视图，随菜单进入。
- 导入 / 导出已移入管理后台的「数据」tab，顶栏不再提供数据入口。
- 主题切换、管理后台、退出。

启动台与工作区的顶栏共用同一套 AppHeader + Brand + 菜单组件，标识、高度、圆角与字号层级一致。顶部不再占用独立的「导入 / 导出」按钮，数据备份与恢复统一收进后台，窄屏顶栏更精简。

### 侧边栏（响应式）

同一份索引，两种归宿：

- `lg`（≥1024px）及以上：索引栏以独立圆角浮层常驻左侧，只保留「全部」「常用入口」与「分类」三组，避免信息过密。
- `lg` 以下：索引栏收进抽屉，从顶栏按钮唤起，选完分类自动收起。
- 工作区默认落地「常用入口」（置顶书签）；「全部」展示全部活动书签（按分类分组），点击时 URL 显式带 `pinned=false`，避免被「常用入口」的默认值吞掉。
- 「归档」「回收站」不在索引栏，收纳进右上角菜单，随视图切换进入。

### 分类与标签操作

- 分类是可展开/收起的树形索引，位于「常用入口」下方；每行左侧为图标、名称与书签计数，展开箭头位于行最右侧，点击箭头仅展开/收起、点击主体进入对应分类视图（含子分类），再点当前分类可取消筛选回到全部；节点带计数。管理后台入口只在右上角菜单（侧栏不再提供「管理分类」快捷入口）。分类与标签筛选可叠加，二者互不重置。
- 落地页（无任何筛选的活动视图）按顶层根分类分区展示全部网站：子分类书签并入所属根分类，未分类书签单独成区并置于末尾。
- 标签不做侧栏列表，只在内容区以「筛选」按钮 + 按钮正下方展开的面板呈现（搜索框下方，仅活动视图；内联渲染而非浮层，展开轻量无卡顿）：面板内标签平铺换行、带计数，单选；选中后触发按钮显示当前标签，再点选中标签或面板内「清除」即清除。点击标签或卡片上的标签直接进入对应标签视图，可与分类叠加。标签胶囊（TagChip）在筛选面板与书签卡片上样式一致。
- 书签卡片上的分类与标签仍可点击筛选，但只作为卡片内的轻量信息，不承担主导航。
- 活动书签的整张卡片都是新标签页跳转的命中区域；置顶、归档、编辑、删除、分类与标签保持为独立可点击控件。
- 添加/编辑书签时，标签以已选胶囊呈现；输入后按回车确认，也可以从已有标签建议中点选。分类以树形下拉选择，保存时按现有 API 的 `categoryId` 契约提交。

### 管理后台（站内侧边栏页）

分类、标签与设置不再以弹窗形式存在于工作区，统一收到独立的「管理后台」页（从右上角菜单进入），采用侧边栏式导航（桌面端常驻浮动栏、移动端抽屉），主工作区保持书签浏览与卡片操作能力：

- 概览：四态书签计数 + 分类/标签数统计卡片，可一键进入对应管理栏。
- 网站：统一的轻量级网站（书签）数据表格管理——全状态浏览（全部/活动/归档/回收站）、搜索、分类/标签筛选、「仅常用」；以紧凑表格展示 Favicon、标题描述、网址域名、分类标签与状态胶囊，支持新建/编辑、置顶、归档、移入回收站、恢复与永久删除（危险操作二次确认），摆脱前台书签柜的重型卡片感。
- 分类：带清晰树形导轨（Tree Guide Lines）与层级阶梯的树形管理（新建一级/子级、重命名、改图标、同级上下移、「调整层级/移动到…」改父级、删除）；书签数显示为「直属 / 含子类总数」；删除确认会说明将上移的子分类数与改为未分类的书签数。
- 标签：列表 + 计数 + 筛选；新建、行内重命名、合并到其他标签、删除；合并与删除均有确认与影响说明。
- 设置：背景图片（开关 + 网址 + 预览）+ Favicon 自动获取工具与开关 + 搜索引擎管理（内置预设 + 自定义引擎增删改、默认引擎单选；内置项不可删除，改动保存到服务端，启动台跨设备生效）。
- 数据：导入 / 导出（导出 JSON 完整备份与 HTML 浏览器书签、拖放导入并自动识别格式），原顶栏菜单的数据入口已移除。

后台 tab 与工作区筛选均由 URL 驱动（`/admin/<tab>` 与 `/workspace?view=&category=&tag=&q=`），可直接深链、可回退；后台沿用主工作台的视觉 token 与圆角语言，侧边栏用 shadcn Sidebar 原语（`SidebarProvider` / `Sidebar` / `SidebarInset` + `SidebarTrigger`），桌面常驻浮动圆角栏、移动端抽屉，导航项选中态随当前路径高亮，底部提供动态「返回启动台 / 返回书签柜」（基于前台 UI 记忆状态）与「退出登录」。

### 前台双 UI 状态记忆

系统提供两种前台体验：启动台（`/`）与书签柜（`/workspace`）。

- 状态记忆：用户在前台切换访问任一界面时，将自动记录最近访问的偏好视图。
- 登录重定向：登录完成或已登录访问根路径时，自动跳转至记忆的前台视图。
- 后台返回联动：从管理后台侧边栏底部点击返回时，按记忆返回对应的启动台或书签柜，而非写死跳转书签柜。

### 危险操作确认

凡是不可逆或影响面大的操作必须二次确认（`AlertDialog`，取消为默认焦点）：书签「移入回收站 / 归档 / 永久删除」，分类「删除」，标签「删除 / 合并」。确认文案明确说明影响与恢复方式；确认后请求期间按钮禁用，成功后以 toast 反馈。恢复、置顶、编辑等轻操作不弹确认。

## 组件组合

界面不手写临时 markup，一律从项目内本地化的 shadcn/base-nova 组件（`src/web/components/ui`）组合：

- 骨架与导航：Sidebar 系（侧边栏索引、导航结构），配合 AppShell 工作台壳。
- 覆盖层：Dialog、AlertDialog；覆盖层必须带标题，视觉隐藏用 `sr-only`。
- 内容块：优先使用现有 Card 系；简单空状态和加载占位可保持功能内局部结构，不为一次性布局新增组件文件。
- 表单：Field 组合（Field + FieldLabel + Input / Select / Textarea / Checkbox），校验用 `data-invalid` + `aria-invalid`。
- 反馈与点缀：优先使用已安装的 toast、Badge、Separator、DropdownMenu 等，不保留未使用的 UI 文件。
- 图标只用 lucide-react，按钮内图标走 `data-icon`，不写尺寸类。

以上是组合惯例：具体以 `src/web/components/ui` 中已安装的组件为准，缺的组件按需补装进同一目录，而不是手写自定义结构替代。配色只走语义 token（paper/ink/rule 落到 background/foreground/border，seal/rust 落到 primary 等），组件不写死 hex，也不做手写 `dark:` 覆盖。

## 不做什么

不套奶油底+衬线模板的大数字 hero；不套黑底酸绿；扩展页面不套这套皮肤。
